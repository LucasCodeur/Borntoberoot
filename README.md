# Born2beRoot

## Overview

**Born2beRoot** is a project from the **42 curriculum** focused on system administration, Linux configuration, virtualization, security, and server management.

The goal is to set up and secure a virtual machine running a Linux distribution while following a set of system administration requirements.

## Objectives

* Set up a Linux virtual machine.
* Configure partitions and storage.
* Manage users and groups.
* Configure `sudo` and access permissions.
* Implement a strong password policy.
* Configure SSH access.
* Configure a firewall.
* Manage system services.
* Set up scheduled monitoring.
* Understand basic server security principles.

## System Administration

The project involves configuring several aspects of a Linux server:

* User and group management.
* File permissions and ownership.
* `sudo` configuration.
* SSH configuration.
* Firewall rules.
* Password policies.
* Disk partitioning.
* System services.
* Monitoring and resource usage.
* Automated system checks.

## Security

Security is a central part of Born2beRoot.

The project requires implementing measures such as:

* Restricting SSH access.
* Configuring a firewall.
* Enforcing password requirements.
* Limiting administrative privileges.
* Managing file and directory permissions.
* Monitoring system activity.

The objective is to understand how basic security mechanisms can be combined to harden a Linux server.

## Skills Developed

* **Linux**
* System administration
* Virtualization
* Debian
* Shell scripting
* User and group management
* File permissions
* SSH
* Firewall configuration
* `sudo`
* Disk partitioning
* Process and service management
* System monitoring
* Linux security

## What I Learned

Born2beRoot gave me a better understanding of how a Linux server is configured, secured, and maintained.

The project also helped me become more comfortable with the command line and understand the relationship between **users, permissions, services, networking, and system security**.

It provided a practical introduction to Linux system administration and server infrastructure.

# Born2beRoot

## Présentation

**Born2beRoot** est un projet du cursus **42** axé sur l’administration système, la configuration Linux, la virtualisation, la sécurité et la gestion de serveurs.

L’objectif est de configurer et sécuriser une machine virtuelle fonctionnant sous une distribution Linux en respectant un ensemble de contraintes d’administration système.

## Objectifs

* Mettre en place une machine virtuelle Linux.
* Configurer les partitions et le stockage.
* Gérer les utilisateurs et les groupes.
* Configurer `sudo` et les permissions d’accès.
* Mettre en place une politique de mots de passe sécurisée.
* Configurer l’accès SSH.
* Configurer un pare-feu.
* Gérer les services système.
* Mettre en place une surveillance automatisée.
* Comprendre les principes fondamentaux de la sécurité serveur.

## Administration système

Le projet demande de configurer différents aspects d’un serveur Linux :

* Gestion des utilisateurs et des groupes.
* Permissions et propriétaires des fichiers.
* Configuration de `sudo`.
* Configuration de SSH.
* Règles du pare-feu.
* Politique de mots de passe.
* Partitionnement du disque.
* Gestion des services système.
* Surveillance de l’utilisation des ressources.
* Vérifications automatisées du système.

## Sécurité

La sécurité constitue une partie importante de Born2beRoot.

Le projet demande notamment de mettre en place :

* La restriction de l’accès SSH.
* La configuration d’un pare-feu.
* Des exigences concernant les mots de passe.
* La limitation des privilèges administratifs.
* La gestion des permissions des fichiers et répertoires.
* La surveillance de l’activité du système.

L’objectif est de comprendre comment différents mécanismes de sécurité peuvent être combinés afin de renforcer la protection d’un serveur Linux.

## Ce que j’ai appris

Born2beRoot m’a permis de mieux comprendre comment un serveur Linux est configuré, sécurisé et maintenu.

Le projet m’a également permis de devenir plus à l’aise avec la ligne de commande et de comprendre les interactions entre **utilisateurs, permissions, services, réseau et sécurité système**.

Il constitue une première expérience pratique de l’administration Linux et de la gestion d’une infrastructure serveur.
